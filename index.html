Autonomous Agent Pipeline

Every cycle: perceive → reason → act → remember. Aether doesn't wait for prompts — it works continuously.

PERCEIVE

Scans all services every 30s. Detects offline nodes, rate limits, balance changes. Reads environment state from soul_state.json.

REASON

Evaluates 4+ decisions per cycle. Chooses best provider for current load. Decides whether to speak, flag, or escalate.

ACT

Executes decisions: speaks via TTS, flags offline services, spawns agents, writes Rust code to kernel modules.

REMEMBER

Persists every decision, event, and lesson to soul_state.json. Injects recent memories into future conversations. Never forgets.
